Bienvenido a mi sitio web con Hugo

¡Hola mundo! Este es mi primer sitio web creado con el generador de sitios estáticos Hugo, correspondiente a la práctica IAW - P1.2 de 2º de ASIR.

¿Por qué Hugo?

  • Ultra rápido: compila miles de páginas en milisegundos.
  • Sin base de datos: todo se escribe en Markdown y plantillas HTML.
  • Fácil despliegue: genera archivos HTML, CSS y JS planos que pueden servirse con servidores ligeros como Nginx o Apache.
