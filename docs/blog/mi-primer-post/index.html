Empezando a jugar en la Web con Hugo (IAW P1.2)

Publicado el 28/10/2026

Hoy he completado las lecciones de Hugo Codex para entender el funcionamiento interno de Hugo sin necesidad de utilizar plantillas externas complejas:

  1. Instalación de Hugo: Verificación de la versión en Debian.
  2. Estructura HTML básica: Creación de plantillas personalizadas.
  3. Gestión de contenidos: Markdown con frontmatter YAML/TOML.
  4. Parciales reutilizables: Separación de cabecera y pie de página.
  5. Páginas independientes: Creación de la página “Sobre mí”.
  6. Sección de Blog: Listado dinámico de entradas utilizando bucles range.

El principio rector de esta práctica ha sido mantenerlo simple: KISS (Keep It Simple, Stupid).
